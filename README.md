# Hartslagketting 013

Prototype voor het Valentijnsfeest van Poppodium 013 (Hackathon 6, Niet-zo-single-feestje).

Een hartketting met een led die knippert op je hartslag. Met een knop kies je je status: single, bezet of ingewikkeld.

## Techniek

- Arduino Uno
- Prototype in Tinkercad Circuits
- Hartslag wordt nagedaan met een potmeter en met dummydata
